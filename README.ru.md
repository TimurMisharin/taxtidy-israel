# TaxTidy Israel

TaxTidy Israel — плагин ChatGPT с открытым исходным кодом для проверки налоговых документов в Израиле. Он помогает выбрать порядок действий по каждому году, сверить зарплату и удержанный налог, проверить пожертвования по статье 46 и понять, чем подтверждается подача декларации. Встроенный калькулятор поддерживает ограниченный набор ситуаций за **2025 год**.

### Установка через каталог репозитория на компьютере

1. Установите [Codex CLI](https://learn.chatgpt.com/docs/codex/cli) и войдите в аккаунт. Выполните команду в Terminal на macOS или PowerShell на Windows.

   ```sh
   codex plugin marketplace add TimurMisharin/taxtidy-israel
   ```

2. Перезапустите приложение ChatGPT. Откройте **Plugins**, выберите каталог **TaxTidy Israel**, откройте плагин и нажмите **Install plugin**.
3. Если каталог не появился, проверьте, выполнилась ли команда и разрешают ли приложение и рабочее пространство пользоваться локальными каталогами. [Инструкция OpenAI по каталогам](https://developers.openai.com/plugins/build/plugins#add-a-marketplace-from-the-cli)

### Рабочее пространство с администратором

Администратор открывает **Admin → Plugins → Add → Import marketplace**, вводит `https://github.com/TimurMisharin/taxtidy-israel` в **Source**, оставляет **Path** пустым и не указывает ссылку Git, чтобы получать обновления из `main`. При запросе он разрешает доступ к GitHub, проверяет результат импорта и открывает участникам возможность установить плагин. [Инструкция OpenAI по импорту](https://learn.chatgpt.com/docs/enterprise/plugin-management)

## Начало работы

1. Откройте новый чат и выберите **@TaxTidy Israel**. Язык по умолчанию — иврит. Можно запросить ответ на русском, английском или арабском.
2. Укажите год и цель. Например: «Помоги проверить мои налоги в Израиле за 2025 год. Сначала перечисли документы и объясни, что подтверждает каждый из них».
3. Проверьте запрошенные оригиналы, например **טופס 106** (форму 106), банковские справки и квитанции о пожертвованиях. Уточните, что уже сверено, чего не хватает и какой официальный шаг нужен дальше.

Консультационные подсказки доступны без запуска локальных команд. Для калькулятора за **2025 год** и инструментов PDF/OCR нужна совместимая приватная среда Python/POSIX с отдельными зависимостями. Сверяйте извлечённые суммы с оригиналами. Плагин по умолчанию не подключается к налоговому кабинету и не подаёт декларации. Не размещайте налоговые документы и данные для входа на GitHub.
