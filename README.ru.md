# TaxTidy Israel

TaxTidy Israel — плагин с открытым исходным кодом для ChatGPT и Codex. Он помогает проверить израильские налоговые документы. Укажите налоговый год и цель проверки. Плагин поможет собрать документы, сверить доходы и удержанный налог и понять, какие подтверждения нужны для выбора способа подачи.

**[Скачать TaxTidy Israel 0.1.5](https://github.com/TimurMisharin/taxtidy-israel/releases/tag/v0.1.5)** · [Установка и локальные инструменты](taxtidy-israel/SETUP.md) · [Конфиденциальность](PRIVACY.md)

## Что можно проверить

- Справки работодателей **טופס 106**, расчётные листки, удержанный налог и документы по пожертвованиям по статье 46. Плагин показывает, какие суммы совпадают и что нужно уточнить.
- Порядок подачи годовой декларации или заявления на возврат по каждому году. Версия 0.1.5 различает совместную декларацию, раздельный расчёт налога и подтверждённую раздельную подачу супругов. Она проверяет регистрацию выбора по **טופס 4430** для нужного года и учитывает письменное указание исправить уже поданную семейную декларацию.
- Статус подачи по документам. Можно отдельно проверить черновик, подтверждение подачи, полученное вложение, принятое исправление и налоговое уведомление. Подпись и подачу выполняете вы.
- Локальная проверка PDF, распознавание текста на иврите и английском и предварительный расчёт для **поддерживаемых случаев за 2025 год**. Для этих функций нужна совместимая частная среда Python/POSIX. [Возможности и ограничения](taxtidy-israel/VERIFICATION.md)

## Установка и скачивание

| Где хотите использовать | Как начать |
| --- | --- |
| **ChatGPT для macOS или Windows** | Добавьте каталог из GitHub через Codex CLI, затем установите TaxTidy Israel в разделе **Plugins** приложения. Локальный запуск калькулятора и OCR в Windows пока не проверен. |
| **ChatGPT в браузере, на Linux или телефоне** | Откройте **Plugins**, если плагин доступен в вашем рабочем пространстве или каталоге. Администратор может импортировать каталог из GitHub и открыть доступ участникам. |
| **Переносимая сборка** | Скачайте `taxtidy-israel-0.1.5.zip` и файл `.sha256` со страницы релиза. Инструкция по локальным инструментам находится в архиве. |
| **Сборка для каталога OpenAI** | Скачайте `taxtidy-israel-0.1.5-openai.zip` и соответствующий `.sha256`. Для публикации в каталоге предусмотрены отдельная подача и проверка. |

Для установки в приложении на компьютере установите Codex CLI, войдите и выполните:

```sh
codex plugin marketplace add TimurMisharin/taxtidy-israel --ref v0.1.5
```

Перезапустите ChatGPT и установите **TaxTidy Israel** через **Plugins**. В рабочем пространстве администратор может открыть **Admin → Plugins → Add → Import marketplace**, указать `https://github.com/TimurMisharin/taxtidy-israel` как источник, оставить **Path** пустым и настроить доступ после импорта. [Инструкция для приложения](https://developers.openai.com/plugins/build/plugins#add-a-marketplace-from-the-cli) · [Импорт в рабочее пространство](https://help.openai.com/en/articles/20001504-importing-and-syncing-plugin-marketplaces-from-github)

## Первая проверка

Откройте новый чат, выберите **@TaxTidy Israel** и напишите:

> Помоги мне проверить налоги в Израиле за 2025 год. Ответь по-русски. Дай список документов и объясни, как подтвердить подходящий порядок подачи.

Язык по умолчанию — иврит. Также доступны русский, английский и арабский. В чате используйте вымышленные примеры или фрагменты без персональных данных. Храните оригиналы и документы дела вне репозитория. [Пример с вымышленными данными](taxtidy-israel/DEMO.md) · [Конфиденциальность](PRIVACY.md)
