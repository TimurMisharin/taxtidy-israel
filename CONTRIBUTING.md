# Contributing to TaxTidy Israel

Open an issue for a reproducible problem or a clear suggestion. For code or documentation changes, fork this repository, create a topic branch and open a pull request targeting `main`. Only `TimurMisharin` merges pull requests. Contributors do not need write access to this repository.

Use fictional examples only. **Never post taxpayer documents, financial records, account identifiers, email addresses, passwords, one-time codes or signing keys** in issues, pull requests, logs or images. Remove personal information before sharing a reproduction. This public repository is not a private tax-support channel.

Keep changes focused and explain what changed and how you checked it. See [development](DEVELOPMENT.md) for the existing checks. New numerical support requires year-specific official sources and appropriate validation; researching a year does not activate it.

Original project contributions are under [AGPL-3.0-only](LICENSE). Preserve [third-party notices](THIRD_PARTY_NOTICES.md). No contribution grants an exemption from dependency licenses.
