# TaxTidy Israel

TaxTidy Israel הוא תוסף קוד פתוח ל־ChatGPT ול־Codex שעוזר לבדוק מסמכי מס בישראל. בוחרים שנת מס ומגדירים מה רוצים לבדוק. התוסף עוזר לאסוף מסמכים, להשוות הכנסות וניכוי מס במקור, ולברר מה חסר כדי לקבוע את דרך ההגשה.

**[הורדת TaxTidy Israel 0.1.5](https://github.com/TimurMisharin/taxtidy-israel/releases/tag/v0.1.5)** · [התקנה וכלים מקומיים](taxtidy-israel/SETUP.md) · [פרטיות](PRIVACY.md)

## לפני ההתקנה

התוסף מסופק כמות שהוא ואינו תחליף לייעוץ מס, ייעוץ משפטי, פיננסי, חשבונאי או ייעוץ מקצועי אחר. החבות בגין הפסדים מוגבלת במידה שהדין החל מתיר זאת. בחירה להתקין או להפעיל את התוסף לאחר שההודעה הועמדה לעיון מראש מהווה הסכמה לתנאיה, בכפוף לדין החל. [הודעה משפטית והגבלת אחריות](taxtidy-israel/LICENSE-NOTICE.md)

## מה אפשר לבדוק

- **טופסי 106**, תלושי שכר, ניכוי מס במקור ואסמכתאות לתרומות לפי סעיף 46. בודקים אילו סכומים תואמים ואילו דורשים מסמך או בירור.
- דרך הגשת דוח שנתי או בקשת החזר בכל שנת מס. גרסה 0.1.5 מבחינה בין דוח משותף, חישוב מס נפרד והגשת דוחות נפרדים לאחר אימות. היא בודקת אם הבחירה לפי **טופס 4430** נרשמה לשנה המתאימה ומתייחסת להנחיה בכתב לתיקון דוח משפחתי שכבר הוגש.
- מצב ההגשה לפי אסמכתאות לטיוטה, אישור הגשה, מסמך שנקלט, תיקון דוח או הודעת שומה. החתימה וההגשה מתבצעות על ידיכם.
- בדיקת קובצי PDF, זיהוי תווים בעברית ובאנגלית, ומחשבון אומדן למקרים נתמכים ב־**2025**. הכלים המקומיים דורשים סביבת Python/POSIX פרטית ותואמת. [יכולות ומגבלות](taxtidy-israel/VERIFICATION.md)

## התקנה והורדה

| היכן משתמשים | איך מתחילים |
| --- | --- |
| **אפליקציית ChatGPT ב־macOS או Windows** | מוסיפים את קטלוג התוספים מהמאגר באמצעות Codex CLI ומתקינים את TaxTidy Israel דרך **Plugins**. הרצה מקומית של המחשבון ו־OCR ב־Windows טרם אומתה. |
| **ChatGPT בדפדפן, ב־Linux או בנייד** | פותחים את **Plugins** אם התוסף זמין במרחב העבודה או בקטלוג שלכם. מנהל מרחב העבודה יכול לייבא את הקטלוג מ־GitHub ולהנגישו לחברים. |
| **חבילת התקנה עצמאית** | מורידים מהגרסה את `taxtidy-israel-0.1.5.zip` ואת קובץ ה־`.sha256` שלו. הוראות לכלים המקומיים נמצאות בחבילה. |
| **חבילה להגשה לקטלוג OpenAI** | מורידים את `taxtidy-israel-0.1.5-openai.zip` ואת קובץ ה־`.sha256` שלו. פרסום בקטלוג כפוף להליך נפרד של הגשה, בדיקה ואישור. |

להתקנה באפליקציית המחשב, מתקינים את Codex CLI, מתחברים ומריצים:

```sh
codex plugin marketplace add TimurMisharin/taxtidy-israel --ref v0.1.5
```

מפעילים מחדש את ChatGPT ומתקינים את **TaxTidy Israel** מתוך **Plugins**. מנהל מרחב עבודה יכול לפתוח **Admin → Plugins → Add → Import marketplace**, להזין `https://github.com/TimurMisharin/taxtidy-israel` כמקור, להשאיר את **Path** ריק ולהגדיר גישה לחברים לאחר הייבוא. [הוראות לקטלוג מקומי](https://developers.openai.com/plugins/build/plugins#add-a-marketplace-from-the-cli) · [ייבוא למרחב עבודה](https://help.openai.com/en/articles/20001504-importing-and-syncing-plugin-marketplaces-from-github)
